# Fonts

`lmroman10-bold.otf` is Latin Modern Roman 10 Bold, the OpenType twin of Computer Modern
Bold, copied unchanged from the TeX Live tree (`texmf-dist/fonts/opentype/public/lm/`). It is
the default font of the decorated initial: the letter's outline is read from it.
